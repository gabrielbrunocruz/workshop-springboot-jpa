# Workshop Spring Boot e JPA 🍃

Este repositório contém o projeto prático desenvolvido durante o Workshop de Spring Boot e JPA, que faz parte do curso de Java ministrado pelo professor Nélio Alves.

## 💻 Sobre o Projeto

O objetivo deste projeto é colocar em prática os conceitos de desenvolvimento web e a criação de uma API RESTful utilizando o ecossistema Spring. Durante o desenvolvimento, aplicamos conceitos fundamentais da Engenharia de Software e boas práticas, incluindo:

* Desenvolvimento em arquitetura de camadas (Resource, Service, Repository).
* Mapeamento Objeto-Relacional (ORM).
* Criação e divisão de perfis de projeto (Test e Production).
* Operações de CRUD (Create, Read, Update, Delete).
* Tratamento de exceções adequado para APIs.
* Deploy da aplicação na nuvem.

## 🛠️ Tecnologias Utilizadas

* **Java** 
* **Spring Boot:** Framework principal para a criação da aplicação.
* **Apache Tomcat:** Servidor web embutido para execução do projeto.
* **Spring Data JPA & Hibernate:** Ferramentas para o mapeamento objeto-relacional (ORM).
* **Maven:** Gerenciador de dependências e build do projeto.
* **H2 Database:** Banco de dados em memória, utilizado para o perfil de testes locais.
* **PostgreSQL:** Banco de dados relacional, utilizado para o perfil de produção.
* **Postman:** Ferramenta utilizada para realizar e testar as requisições HTTP da API.
* **Heroku:** Plataforma em nuvem (PaaS) utilizada para o deploy e hospedagem da aplicação.
